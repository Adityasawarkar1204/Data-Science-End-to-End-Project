# Data Science with AI & ML – Practice Project

Author: Aditya Sawarkar

This repository contains end-to-end implementation of multiple 
Data Science tasks including Python foundations, Data Analysis,
Machine Learning models, and an Industry-style ML pipeline.

---

## Project Structure

01_python_foundation  
- Data cleaning script  
- Salary analyzer  
- Utility functions  

02_pandas_visualization  
- Sales dashboard using matplotlib & seaborn  

03_eda  
- Exploratory Data Analysis (Titanic dataset)  
- Missing values analysis  
- Correlation analysis  
- Outlier detection  
- EDA report PDF  

04_machine_learning  
- Classification model (Logistic Regression & Decision Tree)  
- Regression model (Linear Regression & Random Forest)  
- Model performance comparison  

05_end_to_end_project  
- Full ML pipeline using sklearn Pipeline  
- Automatic preprocessing (ColumnTransformer)  
- Model saved as .pkl  
- Separate prediction script
